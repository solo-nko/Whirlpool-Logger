# Status

## Members

### Required

#### Name

Name of the status.

- **Name:** `name`
- **Type:** string

#### Date Created

- **Name:** `createdOn`
- **Type:** DateTime

### Optional

#### Color

Color value, to use for visual customization. Should use hex value.

- **Name:** `color`
- **Type:** string

#### Date Deleted

When status was deleted. If it has not been deleted, this should be undefined.

- **Name:** `deletedOn`
- **Type:** DateTime

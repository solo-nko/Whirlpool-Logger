# Tag

## Members

### Required

#### Id

- **Name:** `id`
- **Type:** ULID/string

#### Label

- **Name:** `label`
- **Type:** string

### Optional

#### Description

Description of the tag's purpose.

- **Name:** `description`
- **Type:** string

#### Color

Color to be used for the chip component. Should be formatted in 6-character HEX code.

- **Name:** `color`
- **Type:** string

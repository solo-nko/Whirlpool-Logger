# Category Editor

This is where you can customize each category to fit your wants and needs. You can change what fields are shown, rename them, as well as add custom fields of your own. You can also customize statuses and tags.

## Category Selection

At the top of the page is the category dropdown. This lets you select which category to customize. The display order is determined by the Display Order field.

## Editor Sections

### Title and Display Order

While it is not currently possible to add or delete categories, you can rename the existing ones, if you want. You can also set the display order for each category. Display Order determines the order--from left to right--in which categories will be listed on the Home, Entry, and Records page. The lower the number, the higher the rank.

### Field Editor

Here you can customize the input fields that appear when creating or editing a whirlpool in the given category. Fields allow you to input various information about the media in question. There are two kinds of fields: default fields and custom fields.

Default fields are marked as **(Default)**. They are present in every category, and you cannot remove them. You can however hide them, if you don't expect to need them. You can also rename them to represent something more appropriate for your purposes.

Custom fields are extra input fields you add to suit your purposes. There are currently four kinds of custom field available: date, number, checkbox, and text. A label (name) for the field is required, but you can also choose to make it required. All required fields must be filled in in order to save the whirlpool. By default, only the title is required.

> [!NOTE]
> For the technically minded, numbers are stored as Javascript numbers, checkboxes as booleans, and text as strings. Dates are stored as strings as well, in date-only ISO format.

### Status Editor

Here you can customize the statuses available when creating or editing a whirlpool in the given category. Some sample statuses are added for each category when you initialize the app for the first time, but you can change them or add your own.

### Tag Editor

Here you can manage the pool of tags available for the category. Tags are assigned to whirlpools like statuses, except whereas a whirlpool can only have one status at a time, you can assign as many tags to it as you want.

## Save Your Changes

Note that most changes on this page will not go into effect until you hit the save button at the bottom.

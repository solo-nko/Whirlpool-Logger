# User Guide

Here you'll find some notes on how to use the Whirlpool Logger. It's not a complicated app, but this meant to be a simple reference for those who would appreciate such a thing.

## User Interface

When you open the app, you'll have a navigation bar on the bottom. This generally persists no matter what screen you're on, and allows you to navigate to each of the main screens.

## Nomenclature

You'll find that this guide uses a few app-specific terms for consistency. They're described below:

### Whirlpool

A whirlpool refers to a single entry for a piece of media. Think of it as a journal entry for whatever thing you're trying to write down your thoughts on. The idea is that each book, game, movie, or television series would be assigned its own whirlpool.

### Category

Whirlpools are organized by category. These are categories of media, and by default the app initializes with four categories: games, books, movies, and television.
